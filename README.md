# Portfólio — Davi Augusto Raimundo

Site estático (HTML, CSS e JS puros, sem build). Publicação: arraste a pasta no Netlify Drop ou conecte este repositório no Netlify.

- `index.html` — conteúdo em português (o que o Google indexa)
- `assets/app.js` — traduções EN/ES, tema, filtros, modal, aviso de privacidade
- `assets/styles.css` — visual (claro/escuro)
- `privacidade.html` — política de privacidade (LGPD)
- `sitemap.xml`, `robots.txt`, `og-image.png`, `netlify.toml` (cabeçalhos de segurança e cache)

Para trocar o print de um projeto: substitua o arquivo em `assets/img/projetos/` mantendo o nome (formato .webp, 1280×800).
Se alterar o script inline do `<head>`, atualize o hash `sha256` no `netlify.toml`.
